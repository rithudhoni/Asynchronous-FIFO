# Asynchronous-FIFO
Designed a parameterized Asynchronous FIFO for safe Clock Domain Crossing (CDC). Implemented dual-port RAM, 2-stage synchronizers, and Gray code pointers to prevent metastability. Verified in Vivado XSim with asynchronous read/write frequencies and achieved positive static timing closure (WNS/WHS) on a Xilinx Artix-7 FPGA.
